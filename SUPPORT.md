# Support Guidelines

Welcome to the **TangoDB** community! If you need help, have questions, or want to discuss storage engine design, here is how you can get support.

---

## Community Channels

### 1. GitHub Discussions
For general questions, design ideas, architecture discussions, or asking how to use TangoDB, please use [GitHub Discussions](https://github.com/gokul-ceo/TangoDB/discussions).

### 2. GitHub Issues
Use [GitHub Issues](https://github.com/gokul-ceo/TangoDB/issues) for tracking actionable work:
* **Bug Reports**: Unexpected behavior, crashes, or data corruption.
* **Feature Requests**: Proposed new storage features, APIs, or performance enhancements.

## Security Concerns

If you need to report a security vulnerability, please do **not** open a public issue. Follow our [Security Policy](SECURITY.md) instead.
