# Security Policy

## Supported Versions

Security updates are provided for the following versions of TangoDB:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

---

## Reporting a Vulnerability

We take the security of **TangoDB** seriously. If you believe you have found a security vulnerability in TangoDB, please report it to us responsibly.

### How to Report

**Please DO NOT open a public GitHub issue for security vulnerabilities.**

Instead, please send a report to our security maintainers at:
* **Email**: [gokuljune2003@gmail.com](mailto:gokuljune2003@gmail.com) (or open a private security advisory on GitHub if enabled).

### What to Include in Your Report

To help us triage and respond to your report quickly, please include:
1. **Description**: A clear description of the vulnerability and its potential impact.
2. **Steps to Reproduce**: Detailed steps, code snippets, or a Proof of Concept (PoC) demonstrating the issue.
3. **Environment**: Operating System, Java JDK version, and TangoDB version used.
4. **Mitigation**: Any known mitigations or suggested fixes (optional).

### Disclosure Policy

* We will acknowledge receipt of your vulnerability report within **48 hours**.
* We will keep you updated as we investigate and develop a patch.
* Once a fix is verified and released, we will publicly disclose the vulnerability and acknowledge your contribution (unless you prefer to remain anonymous).

Thank you for helping keep TangoDB and its community safe!
